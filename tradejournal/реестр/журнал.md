## Сейчас важно

| Тема | Как есть |
|---|---|
| Продукт | Журнал сделок: 1% риск от доступного депозита, частичные тейки, касса, график, месяц |
| Открытые (скрин 23.09.2026) | XRP 1D, LDO 1D, LTC W (БУ +43.69), XRP W |
| Вход | Google + почта/пароль. В шапке буква профиля → «Выйти» |
| Данные | На аккаунт в Postgres/Supabase; локальный кэш; TXT импорт/экспорт |
| Деплой | Чистый архив `zhurnal-sdelok.zip` → Vercel. Живое превью здесь не ломать |
| Grok в UI чистого архива | Нет |

TXT: строки `ЖУРНАЛ v1` / `СТАРТ` / `СДЕЛКА` / `ТЕЙК` / `КАССА` (табы). JSON тоже принимается.

Частичные тейки по открытым сделкам идут в P&L, остаток риска остаётся.

## Как деплоить (из архива)

1. Распаковать `zhurnal-sdelok.zip`
2. Импортировать папку на Vercel
3. Переменные: `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `VITE_AUTH_ENABLED=true`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
4. Google redirect: `https://<домен>/api/auth/callback/google`
5. Миграции таблиц — на сборке (`npm run build`)

Подробности: `README.md` в корне архива.
